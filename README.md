# Western AirTech — Demo Website

A high-converting single-page website built as a demo for **Western AirTech**, an air conditioning and HVAC contractor based in Lusaka, Zambia.

Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies.

---

## Preview

> Dark premium aesthetic, mobile-first, WhatsApp-integrated contact form, Google Maps embed, pricing tiers, before/after gallery, and FAQ accordion.

---

## Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript
- Google Fonts — Cormorant Garamond + Outfit

---

## Features

- Sticky nav with smooth scroll and active link highlighting
- Mobile hamburger menu
- Hero with animated entrance
- Trust bar
- Services, Products, Pricing, Before/After, FAQ, Location, Contact sections
- Pricing tiers in ZMW with addons table
- Before/After job comparison cards
- FAQ accordion
- Google Maps embed
- WhatsApp quote form — pre-fills a message and opens WhatsApp directly
- Floating WhatsApp button
- Fully responsive

## Getting Started

No build step needed. Just clone and open.

```bash
git clone https://github.com/yourusername/western-airtech.git
cd western-airtech
open index.html
```

Or serve locally:

```bash
npx serve .
```

---

## Deployment

Drag and drop the repo folder onto [Netlify](https://netlify.com) — live in under a minute. Works on any static host.

## Notes

- Phone number, address, and business hours are real (sourced from Google Business listing)
- Pricing figures are ZMW market estimates — not confirmed by the client
